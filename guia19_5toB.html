El Límite al Infinito de una Sucesión

Una sucesión es una lista infinita de números a1, a2, a3, …, an, … ordenados por su posición n. El límite al infinito analiza qué pasa a medida que n se hace infinitamente grande.

* Si los términos se aproximan cada vez más a un valor fijo L, la sucesión es convergente y se escribe:
limn → ∞ an = L * Si los términos crecen sin límite hacia el infinito o decrecen sin límite, la sucesión es divergente.

Propiedades Fundamentales (I y II)

Los límites de sucesiones siguen reglas indispensables para su resolución:

Propiedad 1: Unicidad del Límite
Toda sucesión convergente tiende a un único valor. No puede aproximarse a dos valores distintos simultáneamente cuando n → ∞.
* Ejemplo: Si an = 1/n converge a 0, es imposible que también converja a 0.5. El límite L = 0 es exclusivo.
Propiedad 2: Límite de Sucesión Constante
Si todos los términos de una sucesión son iguales a una constante c (la sucesión es c, c, c, …), entonces su límite es exactamente c:
limn → ∞ c = c * Ejemplo: Para la sucesión constante 8, 8, 8, 8, …, el límite es limn → ∞ 8 = 8.

Propiedades Fundamentales (III y IV)

Propiedad 3: Límite Positivo y Signo de Términos
Si una sucesión tiene un límite estrictamente positivo (L > 0), existe un número de término a partir del cual todos los términos siguientes son positivos.
* Ejemplo: Para an = 2 - 5/n, los primeros términos son negativos (a₁ = -3, a₂ = -0.5), pero como su límite L = 2 es positivo, a partir de n = 3 (a₃ = 0.33) todos los términos siguientes son positivos.
Propiedad 4: Comparación del Grado de Polinómicos
Para una sucesión racional an = P(n)Q(n), si el grado del polinomio del numerador es menor que el del denominador, entonces la sucesión es convergente y su límite es igual a 0.
* Ejemplo: En an = n² + 2n³ + 5, el grado del numerador (2) es menor que el del denominador (3), por lo tanto: limn → ∞ an = 0

Evaluación Teórica 1

Si aplicamos la propiedad de grados polinómicos a la sucesión racional an = 3n² - n + 25n³ + 4n - 1, ¿cuál es el límite de la sucesión cuando n tiende al infinito?

Evaluación Teórica 2

Si una sucesión convergente an se analiza por computadora y se determina que cuando n → ∞ sus términos se aproximan al valor L1 = 4.00, ¿es posible que otra fórmula demuestre que el límite también es L2 = 4.01?

Evaluación Teórica 3

Si una sucesión constante posee todos sus términos iguales a -5 (es decir, -5, -5, -5, …), ¿cuál es su límite cuando n tiende al infinito?
